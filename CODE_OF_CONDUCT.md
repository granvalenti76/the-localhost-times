# Code of conduct

The Localhost Times follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), version 2.1.

In short: be kind, assume good faith, criticise the code and never the person, and keep other people's private data out of issues, screenshots and logs. Harassment of any kind is not tolerated.

Report unacceptable behaviour privately through GitHub's **Report content** option, or to the maintainer through the address on their GitHub profile. Reports are read and answered, and kept confidential.
